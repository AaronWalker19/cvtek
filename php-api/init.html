🔧 CVTEK - Initialisation

1️⃣ Initialiser la Base de Données

Crée la table doc_version et migre les documents existants.

2️⃣ Créer Table Commentaires

Crée la table commentaire pour stocker les commentaires sur les versions de documents.

2️⃣ Créer Table Abonnement

Crée la table abonnement pour gérer les abonnements entre professeurs et étudiants.

3️⃣ Normaliser la Structure (Migration)

Enlève les colonnes url_fichier et version de la table documents. Migre les données vers doc_version.

3️⃣ Diagnostiquer l'État

Vérifiez l'état de la base de données et les données existantes.

4️⃣ Initialiser Utilisateur Démo

Crée/vérifie l'existence de l'utilisateur démo mael.

✅ Tout en Un

Lance toutes les initializations en séquence (Setup → Migration → Demo User → Diagnostic).

Après l'initialisation, retournez à l'application
