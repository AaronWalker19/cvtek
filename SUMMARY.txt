## MODE WATCH (The Magic Part)

Every time you modify code:
1. You save (Ctrl+S)
2. Jest detects change
3. Tests rerun (< 2 seconds)
4. You see if it works ✅ or breaks ❌

This is why Jest is awesome!

## HOW IT WORKS (Simple Explanation)

Jest is an automated test runner.

Without tests:
- You manually click everywhere to verify things work
- Slow and easy to forget cases
- Bugs reach production

With Jest:
- You write once: "if I click Login, I should see the form"
- Jest runs this 100 times automatically
- You get instant feedback
- No more bugs in production

## BENEFITS

Before (no tests):
- Manual testing (slow)
- Easy to miss edge cases
- Bugs in production
- Refactoring is risky

After (with Jest):
- Automated testing (fast)
- All cases tested
- Bugs caught before production
- Refactoring is safe
